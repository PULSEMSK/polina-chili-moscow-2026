## Временный переход на Ticketland · 11 октября 2026

По поручению владельца все шесть кнопок покупки ведут на
https://www.ticketland.ru/drugoe/restoran-original/polina-chili-hb-party-1/.
HTML-ссылки работают без JavaScript. `widget-config.js` задаёт адрес с прежними
UTM по умолчанию; `app.js` сохраняет передачу UTM из текущей сессии и входящего
`yclid`. Скрипт и атрибуты перехвата Ticketscloud отключены. Цены и оформление
не менялись. Пункты навигации «Билеты» по-прежнему открывают раздел тарифов.

Возврат — только по отдельному поручению владельца: отменить коммит
`Temporarily route all ticket buttons to Ticketland` через `git revert <SHA>`
и отправить результат в `main`. Это восстановит HTML, конфигурацию и обработчик
Ticketscloud из предыдущей версии (базовый коммит `3dc9da51159118e363213b911e1cd57633eddaf2`).
Если после временной правки сайт изменялся, проверить конфликты и повторить
проверки кнопок, UTM и публикации GitHub Pages. Автоматического возврата нет.
